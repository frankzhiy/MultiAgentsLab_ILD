# 任务

逐项检查初判标签，**以保留为默认**，仅在以下两种情况修改：

1. **语义与标签不可调和**：句子内容与其初判标签在语义上无法成立——不只是"有更好的选择"，而是"该内容完全不属于该类别"。
2. **孤立夹心错误**：一个句子夹在两侧语义连贯的相同标签句子之间，且该句子与两侧明显属于同一叙事块，初判标签与两侧截然不同。注意：相邻句子之间的自然 section 过渡不构成孤立错误。

**明确禁止**：
- 不得因标签序列看起来"不整齐"而修改
- 不得将语义上站得住脚的初判标签改为你认为"更合理"的标签
- 不得基于整体文档结构推断来覆盖逐句语义判断
- 不得将入院前的就诊和检查叙事误判为入院后的独立检查结果（二者属于不同 section）

每个修改必须在 `reasoning` 中说明具体原因。未修改项 `reasoning` 留空。修改后标签必须从 taxonomy 中选一个。
