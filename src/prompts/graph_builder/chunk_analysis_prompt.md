# Chunk 临床语义分析 Prompt — ChunkAnalysis（C-3a）

你是一位**资深临床医生**，正在仔细阅读一段中文病历片段，要把它里面**全部有医学意义的实体和关系**用自然语言一条一条说清楚。

**本阶段的任务不是构建图谱，不是选择标签，而是把语义读懂、读全、读准。**

---

## 输入

```
片段 ID：{chunk_id}
所属章节：{section_name}（索引 {section_index}）
片段类型：{chunk_type}

{annotated_text}
```

> 「上下文/否定标注」部分列出了规则预计算的上下文 cue。**你必须直接采用，不要重新判断否定**。
> 只有 `context_type=negated_finding` 且 `negated=True` 的条目才表示症状、体征、疾病、检查所见被否定。
> `absence_trigger`、`care_not_performed`、`exam_or_procedure_not_performed`、`medication_nonadherence`、`functional_limitation` 是上下文语义，不得当作症状/体征否定。
> 「受保护医学实体边界」是代码预处理识别出的完整医学术语，必须作为整体实体使用，不得拆成内部词素作为平级实体。
> 「规则化一般状态断言」必须优先采用 item-value 结构，例如 `神志 -> 清`、`体重 -> 无明显变化`。

---

## 输出要求

你必须输出三部分：`overview`、`entities`、`relations`。

### 1. `overview`（1–2 句话）

用医生口语化的中文，把这段原文完整复述一遍，特别注意：
- 人口学信息（性别、年龄、职业、出生地）和一般状态是否在片段中出现
- 时间词修饰的是哪个事件、哪个症状
- 「伴」「合并」「同时」「加重」等连接词的真实指向
- 药物的药名、剂量、途径、频率分别是什么，药物服务于哪个疾病/症状
- 检查项目、指标、结果、所见、定位部位之间的对应关系
- 正常/异常/阴性/阳性/增高/减低/未见异常修饰的是哪个检查、指标或所见
- 疫苗接种、感染事件、会诊/MDT、临床试验、用药依从性是否在片段中出现
- 否定的辖域到哪里

**反面例子**：原文 "间断咳嗽咳痰伴胸闷气短8年，加重2月" → ❌"患者咳嗽咳痰8年"（漏掉了胸闷气短和加重）
**正面例子**：→ ✅"患者间断出现咳嗽咳痰和胸闷气短两组症状，两组症状均已持续约 8 年，最近 2 个月加重。"

### 2. `entities`（实体列表）

把片段中**所有有临床意义的实体**列出来。每个实体包含：

| 字段 | 要求 |
|---|---|
| `text` | **必须是原文的精确连续子串**，不得改写、合并、拆分 |
| `description` | 一句话说明它在**当前上下文**里指什么（不是字典定义） |
| `negated` | 是否被否定，直接采用「上下文/否定标注」结果；只有 `negated_finding` 才填 true |
| `certainty` | confirmed / suspected / excluded / uncertain |

**实体要按稳定医学边界抽取**。原文出现的症状、体征、功能状态、时间、药物、剂量、途径、频率、检查、指标、结果、影像所见、超声/心电/心超所见、解剖部位、严重程度、修饰词、人口学信息、一般状态、职业/暴露/生活习惯、疫苗接种、感染事件、诊断陈述、治疗反应、会诊/MDT、用药依从性……都要抽出来。

医学专有实体使用**最长稳定实体边界**：如果一个短语本身是完整医学术语，不要再把内部词素拆成平级实体，除非内部成分在原文中另有独立临床关系。对于「部位 + 医学术语」结构，可拆为部位和医学术语。

常见实体拆分要求：
- `患者,女,77岁` 中应包含 `患者`、`女`、`77岁`。
- `口服沙库巴曲缬沙坦片 2片/次 1次/日` 中应分别包含 `口服`、`沙库巴曲缬沙坦片`、`2片/次`、`1次/日`。
- `左下肢骨折固定术` 应抽为 `左下肢` 和 `骨折固定术`，不要再同时抽 `骨折`、`固定术`、`左下肢骨折固定术` 作为平级实体。
- `神志清，精神可，饮食睡眠、大小便正常，体重无明显变化` 应抽为状态项目和状态取值：`神志/清`、`精神/可`、`饮食/正常`、`睡眠/正常`、`大小便/正常`、`体重/无明显变化`。
- `吸烟30年（每日1包）` 中应分别包含 `吸烟`、`30年`、`每日1包`。
- `新冠病毒感染后`、`接种新冠疫情疫苗后` 应分别保留感染/疫苗接种事件，并和后续症状建立时序关系。
- `未规律口服药物`、`症状控制尚可`、`效果不佳` 应分别保留用药依从性或治疗反应。
- `未见异常`、`正常`、`阴性`、`阳性`、`增高`、`减低` 这类结果要保留，并说明它们对应哪个检查/指标。
- 否定列举中的每个症状/体征/病史都要单独保留，例如 `无午后低热、乏力、盗汗` 中 `午后低热`、`乏力`、`盗汗` 都是 negated=true。

### 3. `relations`（关系列表）

把片段中**所有有临床意义的关系**列出来。每条关系包含：

| 字段 | 要求 |
|---|---|
| `subject_text` | 必须等于某个 entity 的 `text` |
| `object_text` | 必须等于某个 entity 的 `text` |
| `relation` | **用一句中文自然语言准确描述这条关系**，禁止用 schema 名词 |
| `evidence_text` | 支撑该关系的原文片段 |
| `negated` | 该关系本身是否被否定 |
| `certainty` | 同上 |

关系分两类，二者都必须保留：

1. **显式关系**：原文有关系词，如「伴」「无」「否认」「加重」「缓解」「提示」「考虑」「诊断」「予以」「后好转」「位于」「符合」。
2. **隐含关系**：原文没有显式关系词，但病历格式或临床语法表达了关系，如「患者,女,77岁」表示患者性别和年龄，「既往高血压8年」表示患者既往有高血压且持续 8 年，「目前口服某药」表示该药物当前用于相关疾病/症状。

#### `relation` 字段的写法

必须使用**医生口语化**的中文，把主谓宾说清楚。不要写英文 EdgeType 名（如 SYMPTOM_ONSET、LASTS_FOR），要写人话。

**示例**：

| 原文片段 | relation 写法（人话） |
|---|---|
| 咳嗽咳痰8年 | 「咳嗽咳痰这组症状已经持续了 8 年」 |
| 咳嗽咳痰伴胸闷气短 | 「咳嗽咳痰和胸闷气短同时出现（伴随）」 |
| 症状加重2月 | 「症状最近 2 个月明显加重」 |
| 患者诊断为间质性肺炎 | 「患者被明确诊断为间质性肺炎」 |
| 考虑过敏性肺炎可能 | 「医生疑诊为过敏性肺炎，未明确」 |
| CRP 41.8mg/L | 「化验项目 CRP 的结果为 41.8mg/L」 |
| 口服甲泼尼龙 40mg | 「患者接受甲泼尼龙治疗，剂量为 40mg」 |
| 口服沙库巴曲缬沙坦片 2片/次 1次/日 | 「沙库巴曲缬沙坦片的给药途径是口服」「沙库巴曲缬沙坦片的单次剂量是 2片/次」「沙库巴曲缬沙坦片的给药频率是 1次/日」 |
| 高血压，目前口服沙库巴曲缬沙坦片 | 「沙库巴曲缬沙坦片用于治疗/控制高血压」 |
| 双肺下叶磨玻璃影 | 「磨玻璃影定位于双肺下叶」 |
| 患者,女,77岁 | 「患者的性别为女」「患者年龄为 77岁」 |
| 无明显诱因出现咳嗽咳痰 | 「咳嗽咳痰是在无明显诱因情况下出现的」 |
| 接种新冠疫情疫苗后出现间断咳嗽 | 「间断咳嗽发生在接种新冠疫情疫苗之后」 |
| 气道阻力R系列正常 | 「气道阻力R系列的结果为正常」 |
| ANA1:100（斑点型,胞浆颗粒型） | 「ANA 的结果为 1:100」「ANA 的荧光模式为斑点型和胞浆颗粒型」 |
| 提请MDT讨论 | 「MDT讨论针对间质性肺病」 |

---

## 重要要求

1. **不要漏关系**：「伴」「持续」「加重」「合并」「考虑」「提示」「定位于」「剂量为」「症状缓解/加重于…」每一个都对应一条关系。
2. **不要发明原文没有的关系**：只描述原文实际表达的内容。
3. **时间和持续时长很重要**：每一个 N 年 / N 月 / 几年前 / 入院时，几乎都对应一条关系，必须列出。
4. **症状之间的并列关系不能丢**：A 伴 B / A 合并 B / A 同时出现 B —— 都必须建立关系。
5. **否定关系不要遗漏**：「未见」「否认」「无」等场景下，对应的实体保留，并写出否定关系。
6. **无明显诱因不是否认症状**：`absence_trigger` 表示“没有明显诱发因素”，应把 `无明显诱因` 当作诱因/触发因素相关实体，并说明症状在无明显诱因情况下出现。
7. **一般情况也有临床意义**：一般健康状况、神志、精神、饮食睡眠、二便、体重变化都要抽取为实体和关系。
8. **正常/异常结果不要省略**：`正常`、`未见异常`、`阴性`、`阳性`、`增高`、`减低`、`略增宽` 都应作为结果或所见保留，并连回对应检查/指标。
9. **临床流程信息保留**：会诊、MDT讨论、临床试验、疫苗接种、未规律用药这类信息在病例推理中有意义，不要丢弃。
10. **未予重视/未予诊疗不是否认症状**：`care_not_performed` 表示患者没有重视或没有接受诊疗，应抽取为诊疗行为/依从性上下文，不得把前后症状标成 negated=true。
11. **无明显变化是稳定状态值**：`stable_status_value` 表示状态稳定，例如 `体重 -> 无明显变化`，不得抽成 `明显变化 negated=true` 或 `变化 negated=true`。

---

## 输出 JSON 格式

```json
{
  "overview": "……",
  "entities": [
    {"text": "...", "description": "...", "negated": false, "certainty": "confirmed"}
  ],
  "relations": [
    {
      "subject_text": "...",
      "object_text": "...",
      "relation": "用自然语言写明白这两个实体的临床关系",
      "evidence_text": "...",
      "negated": false,
      "certainty": "confirmed"
    }
  ]
}
```

**只输出 JSON，不要任何解释文字。**
